All the items of an order packed into one cell

Goal Split a marketplace export into one row per item to pick, with model, colour and size, and refuse an export whose column was renamed.

The marketplace export gives one row per order. The items are packed into one cell, and each reference packs model, colour and size.

  • one row per item, even when two are identical;
  • the reference cut into model, colour and size;
  • a file whose column was renamed is refused.

What the hub refuses beside split-row

A split order is no longer one row. A dead letter or a validate-row after split-row would skew the count. lm validate refuses both, before anything runs.

  1. 1
    Validate first

    validate-row goes before split-row.

What this step proves

A composition that would skew the run's count is never applied.

Limits

  • A colour holding a dash, like BLEU-MARINE, shifts the size: split counts the cell but does not correct it.
  • OUT counts the orders written; the number of items is read in the table.
  • Two identical lines in the file itself land as one row.
  • Synthetic orders.
