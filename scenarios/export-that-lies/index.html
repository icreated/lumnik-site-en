The export that lies: an unreadable line does not pass in silence.

An ERP exports its article catalogue every night as one file. A label holds the delimiter, unquoted. lumnik sets the line aside with its raw values, removes nothing from the catalogue while it is unreadable, and closes the dead letter only on the run that really read it again.

Limits

  • The hub checks that the named run could carry the line (Completed, same connector, after the letter), not that it wrote it.
  • Each night that reads the line again adds a dead letter: they are closed one by one.
