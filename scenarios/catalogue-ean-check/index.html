The wrong bar code caught at import

Goal Catch wrong bar codes at import.

A catalogue export carries EAN-13 bar codes, some of them wrong. No built-in transformer computes the check digit.

  • the hub's operator drops a Kotlin script
  • the manifest names it, carrying no code
  • a draft that does not compile is refused at validation
  • every code gets a verdict at import.

// Operator-provided: checks an EAN-13 bar code and says why one is wrong.@Suppress("UNCHECKED_CAST")val cells = bindings["cells"] as MutableMap<String, Any?>val ean = (cells["ean"] as? String)?.trim().orEmpty()cells["ean_status"] = if (!Regex("\\d{13}").matches(ean)) {    "malformed"} else {    val sum = ean.take(12).mapIndexed { i, c -> (c - '0') * (if (i % 2 == 0) 1 else 3) }.sum()    if ((10 - sum % 10) % 10 == ean[12] - '0') "valid" else "wrong-check-digit"}

Limits

  • A script runs with all the hub's rights: only the operator installs one.
  • A replaced script applies from the next batch, never mid-batch.
  • The script runs on CSV imports.
  • Synthetic catalogue, codes under the 200 prefix, reserved for in-store use.

The catalogue export carries 10 EAN-13 codes. Three are wrong.

Fictional catalogue · synthetic data

The problem

The last digit is computed.

  • An EAN-13 ends with a check digit.
  • A typing error makes it wrong.
  • No standard tool checks it at import.

The rule

The operator drops a script. The manifest names it.

mapping:
  cell:
    - kotlin:
        script: hooks:ean-check.kts

2 manifests, 24 lines. One script, 10 lines.

Before any import

A wrong script is refused at validation.

  • Line 8, column 20.
  • No connector created.
  • Nothing imported.

The result

Every code gets a verdict.

  • 7 valid codes.
  • 2 wrong check digits: ART-104, ART-108.
  • 1 code of 12 digits: ART-110.

Real values, replay of 28 October 2026.

Security

The script holds all the hub's rights.

  • Only the operator installs it.
  • The integrator picks it by name.
  • The SHA-256 fingerprint says which version runs.
