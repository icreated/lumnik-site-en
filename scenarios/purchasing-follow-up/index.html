And SUP-004? Ask answers the follow-up as the whole question

Goal Let a buyer chain questions without retyping them, showing each time the question understood.

A buyer asks how many orders were cancelled, then "And for supplier SUP-003?", then "And SUP-004?". They do not retype the question.

  • Ask reads each follow-up with the question before
  • it answers the full question and shows it
  • a follow-up the data cannot answer is refused

Limits

  • The question understood comes from the model configured on the hub (qwen2.5-coder:7b here). The hub checks it before using it; another model may phrase it differently.
  • lm sends the previous question only when given it, with --previous.
  • Synthetic orders; one entity, one scope.

Synthetic orders

The problem

A follow-up alone means nothing.

  • "And SUP-004?" has no verb.
  • Without the question before, no answer.
  • And the buyer does not know what was understood.

What answers

26, then 7, then 2.

  • 26 cancelled orders.
  • 7 for SUP-003.
  • 2 for SUP-004.

What had to be written

lm ask --previous

The question before travels with the follow-up.

A 56-line scenario, two declaration files.

The question understood

Shown every time.

Real answer, replay of 3 November 2026.

A follow-up with no answer

"And last Tuesday's?"

  • Understood: the ones cancelled last Tuesday.
  • No column answers it.
  • No query, and it says so.

The limit

The question understood comes from the model.

  • Here qwen2.5-coder:7b, local.
  • The hub checks it before using it.
  • Another model may phrase it differently.
