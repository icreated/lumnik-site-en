A permit about to be granted by the town hall's silence

Goal Be warned seven days before an undecided planning application becomes a tacit decision, by its type and its legal period.

A town hall instructs planning applications. With no decision notified in the period, silence counts as a non-opposition or a tacit permit. A town hall that loses track of a file has decided without meaning to: the warning is worth something only before.

  • the period in months, computed at the door by the operator's script
  • the warning seven days before the deadline
  • the ABF exception written once

The legal period computed at the door

The register of applications arrives over SFTP. The operator's script computes the deadline and the warning.

  • DP: 1 month, PCMI and PD: 2 months, PC and PA: 3 months (R*423-23)
  • warn_on: seven days before the deadline
  • ABF opinion: silence is a refusal (R*424-3), no warning
  • due.column: warn_on, in state EN_INSTRUCTION
  1. 1
    Months, not days

    The script adds months, as the code counts them.

  2. 2
    The exception

    tacit_issue says why a file gets no warning.

What this step proves

A legal period in months is declared once.

// Operator-provided: when a town hall's silence on a planning application becomes a tacit decision, and when to warn.// Code de l'urbanisme R*423-23: 1 month for a prior declaration (DP), 2 for a house (PCMI) or a demolition (PD),// 3 for any other building permit (PC) or a development permit (PA), from the day the file is complete.// R*424-1: silence then counts as non-opposition or a tacit permit. R*424-3: with the ABF's opinion, silence is a// refusal — no tacit decision, so no warning. The warning falls 7 days before the deadline.@Suppress("UNCHECKED_CAST")val cells = bindings["cells"] as MutableMap<String, Any?>val months = when ((cells["type"] as String?)?.trim()) {    "DP" -> 1L    "PCMI", "PD" -> 2L    "PC", "PA" -> 3L    else -> null}val complete = (cells["complete_on"] as String?)?.trim()val abf = (cells["abf"] as String?)?.trim() == "oui"val deadline = if (months == null || complete.isNullOrEmpty()) null else java.time.LocalDate.parse(complete).plusMonths(months)cells["deadline_on"] = deadline?.toString()cells["warn_on"] = if (deadline == null || abf) null else deadline.minusDays(7).toString()cells["tacit_issue"] = when {    months == null -> "unknown type"    complete.isNullOrEmpty() -> "file not complete"    abf -> "ABF opinion: silence is a refusal (R*424-3)"    else -> null}

Limits

  • Extended periods (a commission, a monument, another authorisation) are not read: the script takes the common-law periods.
  • A request for documents that restarts the period is not read: the register gives the day the file was complete.
  • The hundreds of other "silence means consent" procedures are not covered: this scenario takes planning.
  • No decision is taken: lumnik warns the team, the mayor decides and notifies.
  • Five synthetic files, dated from the day of the replay.
