A closed ticket stays open in the hub, as long as only open ones are read.

Goal Follow a Gitea forge's open tickets, paged by its Link header, without keeping open a ticket support has closed.

Support tracks its customer tickets in Gitea. Its API pages like GitHub's: the next page is in the Link header. lumnik follows the header, page after page:

  • reading state=open leaves the tickets closed since open in the hub: they leave the API's filter;
  • reading every state, by what changed since the last run, keeps the hub true: 57 open, as Gitea says.

72 tickets, 3 pages, by the Link header

One rest-generic connector.

  • auth: a read-only Gitea token, stored with lm secret
  • pagination: link-header: follows rel="next" to the last page
  • response_path: $: the body is the list
  • client, blocking: read from the ticket's labels

Every state, by what changed

The same connector, declared differently.

  • state=all: closed tickets are read too
  • state: a column; closed reads closed
  • incremental: since gets the newest updated_at of the previous run

Limits

  • A ticket deleted in Gitea is no longer returned: its row stays in the hub, with its last state.
  • The reread margin is a minute plus the run's length: a ticket changed just before is reread, never lost.
  • The X-Total-Count total is not yet a witness of the count (icreated/lumnik#1632).
  • Demo Gitea forge, synthetic tickets.

The problem

A filter does not see what leaves it.

  • The import reads open tickets only.
  • A closed ticket is no longer returned.
  • Its row stays open.

What is not changed

Gitea stays as it is.

  • A read-only token.
  • Gitea's paging, followed by the Link header.

What had to be written

path: …/issues?state=all
pagination: { kind: link-header }
incremental: { mode: watermark, param: since }

Every state, only what changed.

One 28-line connector.

Red

Gitea: 60 open. The hub: 72.

  • The run is green.
  • 12 closed tickets stay open.

Green

Gitea: 57 open. The hub: 57.

  • The next day, 15 tickets reread, not 95.
  • The state is a column: closed reads closed.

The limit

A deleted ticket is not seen.

  • Gitea no longer returns a deleted ticket.
  • Its row stays in the hub, with its last state.
