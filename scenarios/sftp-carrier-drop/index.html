The carrier's SFTP drop: every night read, put away, and nothing on trust.

A carrier drops livraisons.csv on its SFTP server every night, always under the same name. lumnik reads a night of the same size again, puts each night away under its own name, says on the run a file it could not archive, and refuses a server whose key has changed.

What this step proves

Limits

  • The check before a move is not atomic with it: a file dropped in the milliseconds between them is still moved.
  • A carrier that writes under another name and renames it in is never caught in that window.
  • Simulated SFTP server; synthetic data.
