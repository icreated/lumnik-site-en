Replayed scenarios

Each scenario was replayed on a lumnik hub: the manifests, commands and results shown are the replay's own. The data is synthetic.

CRM

  • Open

    The CRM's SOAP desk: each service read its own way, nothing read twice.

    A 2000s CRM exposes its data through custom SOAP web services: a case's actions in one call, a customer's opportunities page by page on a page number. The password travels inside the envelope. lumnik reads each one the way it reads, carries the service's Fault verbatim, and never sends the same request twice.

Maintenance

  • Open

    The zombie system: thirty years of work orders, the box switched off, the hub still answers.

    A CMMS replaced years ago stays on for a handful of compliance reads a year: the licence, the box, and the one person who can restart it. lumnik reads it one last time, archives what it read under a single digest, then the box is switched off. The next run says why it fails, the pause stops the schedule, and the hub gives back the same bytes as before.
