An inventory of hand-typed URLs: server, port and environment, without touching the export.

The IT team takes over an application inventory kept for years in a spreadsheet. One column holds each application's URL, typed by hand: capitals, pasted spaces, ports sometimes there, sometimes not. They want to know what runs on a server and what is still in staging. The manifest cuts the URL into columns, no code.

The applications in service, the URL cut up

In the cells, order matters: clean removes pasted spaces, lower turns SRV-ERP-PRD01 into srv-erp-prd01, regex-extract pulls protocol, server and port, then the environment from the server name; default names an off-convention host, and lookup translates prd, rec and dev.

What this step proves

A filter on an extracted column answers like one on a source column.

Limits

  • regex-extract does not count a miss: a pattern that does not read a row leaves its columns empty with no alert, and a default downstream may fill them.
  • default fills a constant: a protocol's port is not derived.
  • Synthetic inventory.
