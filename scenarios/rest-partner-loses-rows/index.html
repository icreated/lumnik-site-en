The partner's API loses a page, the run does not lie.

A partner publishes 2,400 partners and their count. One night a page of 100 vanishes; the count stays right. lumnik compares what it read with the total the source declares: the run fails naming the endpoint and both numbers, instead of turning green.

The source's own count is the witness

One endpoint paged by offset; total_path points at the total the API publishes with each page.

  1. 1
    Witness

    A row count the source publishes, never an estimate.

Limits

  • The witness is only as good as a real row count published by the source.
  • The check fires when pagination ends: rows already written stay.
  • A source that publishes no total has no witness.
  • Partner API stand-in; synthetic data.
