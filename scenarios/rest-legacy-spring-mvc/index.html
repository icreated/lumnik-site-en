Spring PetClinic, from before Spring Boot

The problem

The app was written before modern APIs.

  • It answers XML or JSON.
  • The whole list at once, no pages.

What is not changed

The app stays as it is.

  • A WAR on Tomcat.
  • Spring MVC configured in XML.

The first try

The known address answers XML.

  • The hub reads JSON.
  • It refuses and says so, instead of reading 0 rows.

The probe

lm source rest probe … --endpoint /vets.json

The probe finds the list.

It drafts kind: none: no sign of pages in the answer.

What had to be written

pagination: { kind: none, response_path: $.vetList }

One line.

  • 6 vets, one request.
  • A 23-line connector.

The limit

The hub does not read XML.
