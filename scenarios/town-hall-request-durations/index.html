Legacy request-tracking software: four types of request make 83 % of a town hall's processing time

Goal Know which types of request concentrate the processing time, from opening to closing.

A town hall exports its requests, one line per request, with the day it was opened and the day it was closed. Everybody believes the time goes to civil status, half the requests. Nobody has summed the days by type.

  • the duration computed at the door by the operator's script
  • an A, B, C classing of the types by processing days
  • « acte d'état civil » (civil-status certificate), the most frequent type: in B

A duration computed at the door, a classing by type

The export arrives over SFTP: one line per request, dates written dd/mm/yyyy. The operator's script computes the days from opening to closing. The metric sums, per type, the days and the requests.

  • jours: nothing for a request still open, not zero
  • by: [type]: opening a class shows types, not files
  • preset: abc: A, the types of the first 80 % of the days
  1. 1
    A duration, not a delay

    From opening to closing. No deadline is declared: nothing is late.

  2. 2
    The operator's script

    The manifest names a script of the hub's hooks directory. A date in another shape is counted unreadable, not guessed.

What this step proves

A duration the export does not carry is computed at the door, with the software untouched.

  • réclamation voirie (road complaints): 10,578 d, 227 requests
  • permis de construire (building permits): 5,530 d, 67 requests
  • déclaration préalable (prior declarations): 4,624 d, 144 requests

  2. 2
    Road complaints

    6.81 % of the requests, 27.07 % of the days: 51.6 days on average for a closed one.

Limits

  • A duration, not a delay: no deadline is declared. Holding each type to its deadline is a further step.
  • The 65 requests still open count as requests, not as days: a long-open road complaint does not weigh yet.
  • Calendar days, weekends and closures included.
  • Not a workload: a request waiting for the applicant counts its days too.
  • No trend: ten months as one total.
  • 3,335 requests, synthetic.
