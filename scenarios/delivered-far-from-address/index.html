Marked delivered 2 km from the address

Goal Spot each parcel marked delivered far from its address, or with no scan position, as soon as the carrier's file arrives.

"Parcel marked delivered, never received" recurs before the e-commerce mediator, and the seller owes a conforming delivery. The proof-of-delivery file holds the address's position and the scan's on one row. Nobody compares them: lumnik does.

The distance measured at the door

The carrier drops its proofs of delivery over SFTP. The operator's script measures the distance between the scan and the address.

  • kotlin: distance_m, in metres (haversine)
  • distance_m>200: beyond a building's entrance or a GPS error
  • distance_issue=no scan position: with no position, no distance can raise the row
  • the first day lands before the rules

manifests/scan-distance.kts
// Operator-provided: how far from the delivery address the driver's scan was taken, in metres (haversine, the Earth// as a sphere of 6,371,008.8 m). A point missing or out of range gives no distance, and distance_issue says why.@Suppress("UNCHECKED_CAST")val cells = bindings["cells"] as MutableMap<String, Any?>fun coord(name: String, limit: Double): Double? =    (cells[name] as String?)?.trim()?.replace(',', '.')?.toDoubleOrNull()?.takeIf { kotlin.math.abs(it) <= limit }val lat1 = coord("address_lat", 90.0); val lon1 = coord("address_lon", 180.0)val lat2 = coord("scan_lat", 90.0); val lon2 = coord("scan_lon", 180.0)if (lat1 == null || lon1 == null || lat2 == null || lon2 == null) {    cells["distance_m"] = null    cells["distance_issue"] = if (lat2 == null || lon2 == null) "no scan position" else "no address position"} else {    val r = 6_371_008.8    val dLat = Math.toRadians(lat2 - lat1); val dLon = Math.toRadians(lon2 - lon1)    val a = Math.pow(Math.sin(dLat / 2), 2.0) + Math.cos(Math.toRadians(lat1)) * Math.cos(Math.toRadians(lat2)) * Math.pow(Math.sin(dLon / 2), 2.0)    cells["distance_m"] = Math.round(2 * r * Math.asin(Math.sqrt(a))).toString()    cells["distance_issue"] = null}

Limits

  • No transformer measures a distance: it needs the operator's script, installed in the hooks directory.
  • 200 m is a choice: a large site, a locker or a relay point needs its own threshold.
  • A far scan is not a fraud: the decision asks for the proof.
  • The mediator's report gives no figure on these cases: this proof is weaker than others.
  • Six synthetic deliveries in Lyon.
