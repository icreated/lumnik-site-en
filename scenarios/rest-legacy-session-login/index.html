An old app behind a login: lumnik logs in like a user

Goal Read the vets of Spring PetClinic, protected by the Tomcat server's login, without touching the app.

Spring PetClinic from before Spring Boot, behind the server's login (j_security_check). No API token: a form and a session cookie.

  • without auth, Tomcat answers its login page with 200: the hub refuses it, it is not JSON;
  • auth: { kind: session }: the hub logs in and keeps the session, 6 vets;
  • the app restarts, the session is lost: the hub logs in again on its own, once.

auth: { kind: session }

The hub reads a protected page, posts j_username and j_password, and keeps the session cookie (#1751). The password is an lm secret.

  • pre-flight: GET, POST 303, GET of the data
  • the run: one GET
  1. 1
    One login

    The session the pre-flight opened serves the run.

What this step proves

An app without an API is read with a user's account.

The hub logs in again on its own, once

The app restarts: its sessions are lost. Tomcat answers its login page with a new cookie; the hub sees it, logs in again, and replays the request.

Limits

  • A plain form: no JavaScript login, no second factor, no SAML or CAS.
  • The cookie only goes to the login's origin: an endpoint on another host is refused.
  • PetClinic's demo data: 6 vets; a throwaway password, drawn at each replay.

Clinic · vets

The clinic's old app asks for a login.

Its vets must be read, every night.

Spring PetClinic behind Tomcat's login

The problem

No API token.

  • A form, a password.
  • Then a session cookie.

What is not changed

The app stays as it is.

  • The login is the server's.
  • The account is a clinic account.

Without auth

The server answers its login page.

  • With 200, in HTML.
  • The hub refuses it: it is not data.

What had to be written

auth: { kind: session }

The hub logs in like a user.

  • 6 vets.
  • A 30-line connector.

The restart

The app restarts, the session is lost.

  • The hub logs in again on its own, once.
  • The run reads the 6 vets.

The limit

A plain form.

  • No JavaScript login.
  • No second factor.
