Try lumnik Open, on your own machine.

One command installs the hub, its database and its sign-in server. Then load a first export.

1

Prepare the machine

Docker and Docker Compose, with curl, python3, openssl and awk. Use Linux or macOS. On Windows, use WSL2.

Prerequisites · On Windows

2

Start the hub

The script creates the install's secrets, then starts the hub.

 install lumnik Open
$ git clone https://github.com/icreated/lumnik-open.git && cd lumnik-open
$ ./deploy/selfhost/up.sh --build
…
==> hub is healthy
  Hub:       http://localhost:8080   (health: /q/health)
  Keycloak:  http://localhost:8180/realms/lumnik
